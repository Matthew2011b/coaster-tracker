# Lift Hill

An Android app for tracking the roller coasters you've ridden, grouped by manufacturer and model,
so you can see which models you've never ridden and which ones you've completed.

- **Log**: pick a park (GPS picks the nearest) and a coaster, then tap Log.
- **Stats**: progress for every model or manufacturer, with sort options.
- **Parks**: parks ranked by unridden models or unridden coasters.
- **Nearest**: the closest place to ride each model you haven't.
- **Settings**: colors, filters (defunct, kiddie and carnival), Coasterpedia updates, CSV import and export.

Coaster data updates need your own free Coasterpedia API key (developer.coasterpedia.net).

## Getting builds
- Every push to main: Actions tab > latest run > Artifacts.
- Tagged versions (`v0.2`, `v0.3`...): the Releases page.
